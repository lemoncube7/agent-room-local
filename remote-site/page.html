연결 중

채팅방을 선택하세요

원격 1분 사용법

1. PC와 자동 동기화PC의 Agent Room이 켜져 있으면 보낸 메시지가 바로 AI에게 전달되고, 답변이 이 화면에 표시됩니다.
2. PC가 꺼져 있어도 OK이전 대화는 폰에 캐시되어 바로 볼 수 있고, 보낸 메시지는 대기열에 저장되어 PC가 켜지면 자동 처리됩니다.
3. 빠른 명령어 (/)입력창에 /방목록, /에이전트, /테마, /새로고침, /도움말을 입력해 바로 실행할 수 있습니다.
4. 앱처럼 쓰기브라우저 메뉴에서 홈 화면에 추가를 누르면 모바일 앱처럼 전체 화면으로 쓸 수 있습니다.
